- 并行：FSDP (FULL_SHARD), 3 GPU, world_size=3
- 精度：bfloat16 参数+激活, float32 残差累积
- 优化器：完整恢复原2e-5分支step 18,000的AdamW状态；从step 18,001起恒定4e-5
- 每 step token 数：786,432
- gradient_accumulation=4, per_rank microbatch: 16/8/4/2/1 (4K→64K)
- RC 仅在 4K–64K 启用, fraction=0.05

### 训练总览：逐图怎么看

**A. 全部上下文训练MLM（左上）**
横轴是优化步数，纵轴是掩码预测损失，越低越好。浅蓝点是抽样单步值，红线是100步滚动中位数。当前4e-5分支已连续运行2,689步，最近50步训练MLM均值1.018。曲线未见持续失控，但训练拟合不能替代开发集表现。纵轴聚焦后期范围，未展示全部早期高损失峰值。

**B. 五档上下文（右上）**
横轴是优化步数，五色对应4K–64K上下文，各用同长度最近50个点的滚动中位数平滑。图例最近50点均值为4K 1.007、8K 1.004、16K 1.016、32K 1.020、64K 1.012。五档均实际运行；不同长度样本组成不同，不能据较低训练损失宣称长程能力更强。

**C. 学习率与分支边界（左下）**
紫线step 11,000表示从原始checkpoint恢复后改用2e-5；橙线step 18,000表示从该父checkpoint完整恢复后改用4e-5。模型、AdamW、五档采样进度、pair cursor、token账本和三份rank随机状态一并恢复。当前恒定4e-5，没有预热、衰减或自动降回规则。20,500仅为原定比较窗口终点，不再是停训点。
